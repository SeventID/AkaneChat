# Contributing to AkaneChat

Thanks for your interest in contributing!

- Open an issue before large changes.
- Keep changes focused and include tests where practical.
- Never commit credentials, `.env` files, local databases, or personal chat history.
- Run `bun run typecheck`, `bun test`, and `bun run build` before submitting a pull request.
- By submitting a contribution, you agree that it is provided under the Apache-2.0 license.
